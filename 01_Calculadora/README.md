# Calculadora en Python

Calculadora interactiva para consola desarrollada en Python. Permite realizar varias operaciones en una misma ejecución y consultar un historial de resultados.

## Funciones

- Suma
- Resta
- Multiplicación
- División
- Potencia
- Raíz cuadrada
- Porcentaje
- Resto de una división
- Valor absoluto
- Historial de operaciones
- Validación de entradas incorrectas y división por cero

## Requisitos

- Python 3

No es necesario instalar librerías externas.

## Cómo ejecutar el proyecto

1. Abre una terminal en la carpeta `01_Calculadora`.
2. Ejecuta el siguiente comando:

```bash
python calculadora.py
```

En Windows también puedes utilizar:

```bash
py calculadora.py
```

3. Escribe el número de la operación que deseas realizar y sigue las instrucciones del menú.

## Ejemplo

```text
---- CALCULADORA ----
1. Sumar
2. Restar
3. Multiplicar
...
11. Salir

Elige una opción (1-11): 1
Escribe el primer número: 8
Escribe el segundo número: 2
Resultado: 8.0 + 2.0 = 10.0
```
